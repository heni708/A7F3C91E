# 역주행 자전거 접촉사고 — 경위·대응지침·근거 (웹 페이지)

슬라이드 5장과 사고 재구성 개념도 영상을 한 페이지로 묶은 정적 웹사이트입니다.
페이지를 열면 1장의 개념도 영상이 소리 없이 자동으로 반복 재생됩니다.

## 들어 있는 파일

- `index.html` — 슬라이드 페이지 (이 파일이 저장소 맨 위에 있어야 합니다)
- `media/reconstruction.mp4` — 사고 재구성 개념도 영상
- `media/reconstruction.webm` — 같은 영상의 WebM 버전 (MP4를 재생하지 못하는 브라우저용 예비 파일)
- `media/poster.png` — 영상이 뜨기 전, 또는 자동 재생이 막혔을 때 보이는 정지 화면
- `.nojekyll` — GitHub Pages가 파일을 그대로 올리도록 하는 빈 파일 (숨김 파일이라 안 보일 수 있으며, 없어도 동작에는 지장 없음)

## GitHub Pages로 배포하기

1. GitHub에 로그인해 **New repository**로 새 저장소를 만듭니다 (예: `accident-report`).
   무료 계정은 저장소를 **Public**으로 만들어야 Pages를 쓸 수 있습니다.
2. 저장소 화면에서 **Add file → Upload files**를 누르고, 압축을 푼 파일과 `media` 폴더를 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
   `index.html`이 폴더 안이 아니라 저장소 맨 위에 있어야 합니다.
3. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소로 열립니다. 이 주소를 공유하면 됩니다.

## 보는 법

- 컴퓨터: 키보드 ←/→ 또는 화면 아래 **이전/다음** 버튼, **전체 화면** 버튼
- 휴대폰: 세로 화면에서는 슬라이드가 위아래로 이어지는 **스크롤 보기**로 열립니다. 가로로 돌리거나 **한 장씩 보기**를 누르면 한 장씩 넘기며 볼 수 있습니다(좌우로 밀기).
- 영상: 클릭(탭)하면 멈추고, 다시 누르면 재생됩니다. 카카오톡 내부 브라우저처럼 자동 재생을 막는 환경에서는 **▶ 영상 재생** 버튼이 나타납니다.
- **메모** 버튼: 각 슬라이드의 발표자 메모(분석 세부 내용·출처)를 펼칩니다.

## 알아둘 점

- GitHub Pages 페이지는 주소를 아는 사람이라면 누구나 볼 수 있고, Public 저장소의 파일(영상 포함)도 공개됩니다.
  검색엔진에 노출되지 않도록 `noindex` 태그를 넣어 두었지만, 접근 자체를 막지는 못합니다.
- 카카오톡 링크 미리보기에 이미지를 띄우려면 `index.html` 위쪽의 `og:image` 주석 줄에 실제 주소를 넣고 주석을 풀어 주세요.
